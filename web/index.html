Figma → PPTX

Vložte odkaz na snímek nebo rámec ve Figmě. Vznikne editovatelný soubor pro PowerPoint i Google Slides – barvy, gradienty, texty, obrázky a vektory zůstanou zachované.

Ve Figmě: pravé tlačítko na snímku → Copy/Paste as → Copy link to selection. Figma → Settings → Security → Personal access tokens (File content: Read). Token jde přes vaši Netlify funkci jen do Figma API a nikde se neukládá (pokud nezaškrtnete „Zapamatovat“, kdy zůstane jen v tomto prohlížeči).
Vložená písma se zobrazí správně i u klienta, který je nemá nainstalovaná.

Soubory Figma Slides → plugin

Figma API neumí číst soubory Figma Slides (odkazy figma.com/slides/…). Pro ně použijte plugin, který převede snímky přímo ve Figmě – stejným převodníkem, 1:1.

  1. Stáhněte plugin (ZIP) a rozbalte ho.
  2. Otevřete prezentaci v desktopové aplikaci Figma.
  3. Menu → Plugins → Development → Import plugin from manifest… → vyberte manifest.json.
  4. Spusťte Plugins → Development → Figma → PPTX (1:1) → Exportovat PPTX.
Co se převádí a omezení

Rámce → snímky, výplň rámce → pozadí. Tvary, vektory, čáry, texty (font, řez, barvy po znacích, prostrkání, výška řádku), obrázkové výplně, okraje, stíny. Lineární a radiální gradienty jako nativní gradienty, úhlové a diamantové jako přesný obrázek ve výplni.

PPTX nemá masky, blend módy ani rozmazání – masky se vykreslí jako obrázek, rozmazání se vynechá. Fonty musí být nainstalované.
